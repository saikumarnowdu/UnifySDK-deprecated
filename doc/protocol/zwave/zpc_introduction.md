# Z-Wave (ZPC)

The Z-Wave Protocol Controller (ZPC) implements Z-Wave functionality for the Unify SDK.
From `ver_1.7.0` onward, active ZPC development moved to a standalone repository.

## External Repository

- [Silicon Labs Z-Wave Protocol Controller (GitHub)](https://github.com/SiliconLabsSoftware/z-wave-protocol-controller)
- [Silicon Labs Z-Wave Protocol Controller Documentation](https://siliconlabssoftware.github.io/z-wave-protocol-controller)

## In-Repo Technical Reference

Architecture, components, configuration, and build documentation for ZPC as it
existed in Unify SDK tag `ver_1.6.0` is available as Doxygen HTML:

- [ZPC Technical Reference](../../doxygen_zpc_reference/index.html)

Build locally with `make doxygen_zpc_reference` from a configured CMake build directory.
